# 26. Remove Duplicates from Sorted Array

## 题目
- 给定一个非递增array，原地删除重复元素,返回去重后的元素个数。

## 思路
- 因为数组是已排序的，所有相同的元素必定相邻 —— 所以判断重复只需比较相邻元素。
- 设一个慢指针 j，指向"下一个该写入的位置"，从 1 开始（第一个元素天然保留）。
- 第一个元素保持不动，从第二个元素开始用 i 遍历数组。
- 遍历时，判断当前元素是否和前一个元素相同：
  - 不相同 → 说明是一个 distinct（不重复的）新元素 → 把它写到 j 的位置，然后 j 递增。
  - 相同 → 跳过（它是重复的）。
- 最终返回 j，它就是去重后的元素个数。

## 我踩的坑
- nums[i-1] 在 i=0 时,i-1 变成 -1,Python 不报错但 nums[-1] 是最后一个元素 → 比较对- 象完全错了。[1]、[1,1] 这种情况输出错误。教训:想"和前一个比"时,i 要从 1 开始。
- j 初始值的问题:第一个元素天然保留,所以 j 要从 1 开始,不是 0。
- 题目出现 "sorted" 是重要信号 —— 有序意味着相同元素相邻,能用双指针/二分这类快速解法
- 答案不用 set 去算 —— j 本身就在计数

## 解法
```Python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        j = 1
        for i in range(1,len(nums)):
            if nums[i] != nums[i-1]:
                nums[j] = nums[i]
                j += 1
        return j
```

## 复杂度
- 时间 O(n),
- 空间 O(1) - in-place
