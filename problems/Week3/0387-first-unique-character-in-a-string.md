# 387. First Unique Character in a String

## 题目

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

**示例：**
```
输入: s = "leetcode"
输出: 0

输入: s = "loveleetcode"
输出: 2

输入: s = "aabb"
输出: -1
```

## 思路

用哈希表（字典）统计每个字符出现的次数，再遍历原字符串，返回第一个出现次数为 1 的字符的下标。

两次遍历：
1. 第一次遍历字符串，统计每个字符的频次
2. 第二次遍历字符串（保证顺序），找到第一个频次为 1 的字符

## 我踩的坑

1. **`k[0]` 多余**：遍历字典时用了 `k[0]`，但 `k` 本身就是单个字符，`k[0]` 和 `k` 完全等价。

2. **第二次遍历了字典而不是字符串**：遍历字典找到第一个 `v == 1` 的字符后，再用 `s.index(k)` 查找下标，多了一次 O(n) 的查找。正确做法是直接遍历字符串，用 `enumerate` 拿下标，天然保证顺序且无需 `index`。

## 解法

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        d = {}
        for i in s:
            d[i] = d.get(i, 0) + 1
        for i, c in enumerate(s):
            if d[c] == 1:
                return i
        return -1
```

## 复杂度

| | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(n) | 两次线性遍历字符串 |
| 空间 | O(1) | 字典最多存 26 个英文字母，常数空间 |
